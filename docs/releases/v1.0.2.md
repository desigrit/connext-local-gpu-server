Shambu can now keep itself up to date.

- The version sits quietly at the bottom left. When an update appears, download it there and choose **Restart** when you're ready. Android keeps updates with Google Play.
- Closing the desktop window tucks Shambu into the tray. Use **Quit Shambu** from its menu to exit.
- One standard arrow cursor throughout the app.
- Removed the stale-readings message. The last-checked time remains.

Install this version once to get future updates inside Shambu.
