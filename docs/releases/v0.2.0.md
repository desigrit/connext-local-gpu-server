Shambu keeps an eye on your home GPU server, wherever you are.

## Downloads

- **Mac with Apple Silicon:** Shambu-Mac-Apple-Silicon.dmg
- **Windows with Intel or AMD:** Shambu-Windows-x64-Setup.exe
- **Windows with Snapdragon or another ARM processor:** Shambu-Windows-ARM64-Setup.exe
- **Android phone:** Shambu-Android-arm64.apk
- **GPU PC companion:** Shambu-Host-Windows-x64.zip or Shambu-Host-Windows-ARM64.zip

## What changed

A calmer two-second refresh, brief app-launch messages, delayed explanations, 48 hours of GPU activity, visible eight-character pairing codes, and installation actions for missing companion apps.

Install Tailscale on each device and sign in with the same account. In Shambu, choose Remote server, paste the GPU PC’s Tailscale Ollama URL, and enter the code from Settings on that PC. The host companion must be updated to 0.2.0 for short codes.

These are early builds. Windows packages are not publisher-signed; macOS is ad-hoc signed and not notarized. Follow the operating system’s normal approval flow only for downloads from this repository. Android is signed with the project’s locally held release key. If you previously installed a debug APK, uninstall that preview before installing this release.

[Setup and install help](https://github.com/desigrit/shambu/blob/main/docs/install.md) · [Host companion](https://github.com/desigrit/shambu/blob/main/docs/host-agent.md)

No inference requests are sent by the monitor. GPU history is an estimate of activity while Ollama has a model in GPU memory.
