# Icon sources

These icons are Tauri CLI exports of the approved [Shambu pen sketch](../../assets/shambu/shambu.png). The [256-pixel application asset](../../src/assets/shambu-icon.png) is a copy of 128x128@2x.png.

The master is the unchanged approved concept from [shambu-stick-sketch.png](../../../docs/concepts/shambu-stick-sketch.png), generated with the built-in OpenAI image tool using the archived Shikari Shambu portrait. The [prompt](../../../docs/concepts/shambu-stick-sketch-prompt.txt), [source attribution](../../assets/shambu/ORIGIN.txt) and [branding notes](../../../docs/branding.md) record its origin. The attribution notice ships with the app.
