# Icon source

These icons are Tauri CLI exports of [shambu-binoculars.png](../../assets/shambu-binoculars.png), an AI-edited Shikari Shambu illustration made with the built-in image generation tool. The source references were an original Amar Chitra Katha press illustration and a visual reference supplied by the project owner.

The circular jungle composition, smaller grinning character hidden by foliage, greener clothing, and oversized binoculars were requested by the owner. The binoculars deliberately extend beyond the circle. The app's [header and mascot image](../../src/assets/shambu-icon.png) is a copy of `128x128@2x.png`.

The final master and PNG exports embed the exact [refinement prompt](../../assets/shambu-binoculars.prompt.txt). The earlier [base edit prompt](../../assets/shambu-binoculars-base.prompt.txt) is also retained. Creator attribution, unchanged source files, checksums, and rights information are documented in [branding.md](../../../docs/branding.md). This edited artwork must not be described as unchanged original pixels or an original character owned by this repository.
