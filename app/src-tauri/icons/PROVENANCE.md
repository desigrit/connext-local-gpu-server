# Icon sources

These icons are deterministic Tauri CLI exports of [shambu-r2d2.svg](../../assets/r2d2/shambu-r2d2.svg). The composition uses an [editable right-facing R2-D2 drawing](../../assets/r2d2/r2d2-droid.svg) based on the [supplied flat reference](../../assets/archive/r2d2-reference/README.md), the original raster forest from the [earlier Shambu icon](../../assets/archive/shikari-shambu/shambu-binoculars.png), and a narrowly clipped [background repair](../../assets/r2d2/forest-subject-fill.png).

The original canopy outside the former subject footprint and the foreground leaf contours are preserved from the original source image. Only the space formerly occupied by the old man and binoculars uses the background repair, made with the built-in image generation tool using this [exact prompt](../../assets/r2d2/forest-subject-fill.prompt.txt). The smaller droid fits fully inside the circle and faces right. The final droid does not use the retired LibreICONS glyph.

The [256-pixel application asset](../../src/assets/shambu-icon.png) is a copy of `128x128@2x.png`. Derived PNGs embed [ORIGIN.txt](../../assets/r2d2/ORIGIN.txt), including source attribution, checksums, and modification details. Keep that notice with redistributed files. [branding.md](../../../docs/branding.md) records the sources, composition, exports, and character-rights attribution.
