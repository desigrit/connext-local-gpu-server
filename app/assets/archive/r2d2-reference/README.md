# Supplied R2-D2 reference

The project owner supplied [this flat R2-D2 illustration](r2d2-flat-reference.png) as visual inspiration for the final icon. It is preserved unchanged. Its original artist and source URL were not supplied.

The final vector drawing uses its blue, silver, and white palette, cylindrical proportions, panel detail, and side-leg structure, with a new three-quarter pose facing right. See [branding.md](../../../../docs/branding.md). The reference is not bundled as an interface image. No ownership or license to the source illustration is claimed. R2-D2 and Star Wars remain the property of their respective rights holders.
