# Shikari Shambu source archive

These assets preserve the character references and earlier artwork. The original portrait is the reference for the active minimal pen-sketch icon, documented in [branding.md](../../../../docs/branding.md). The jungle and binoculars images remain design history.

Shikari Shambu was created by Luis Fernandes and Vasant Halbe for Tinkle. The publisher is Amar Chitra Katha Pvt. Ltd. The [publisher's 2021 press release](https://www.issuewire.com/tinkles-shikari-shambu-turns-38-1700939605829767) credits Savio Mascarenhas as the illustrator of Shambu's stories at that time, without a separate credit for each attached image.

- [Original portrait source](shikari-shambu-source.png): unchanged [ACK press illustration](https://s3-us-west-2.amazonaws.com/issuewireassets/primg/54661/shikari-shambu896408899.png).
- [Original selfie source](shambu-selfie-source.png): unchanged [ACK press illustration](https://s3-us-west-2.amazonaws.com/issuewireassets/primg/54661/shambu-takes-a-selfie1214805948.png).
- [Jungle reference](shambu-jungle-reference.png): supplied by the project owner; no independent source URL was provided.
- [Former binoculars illustration](shambu-binoculars.png): an AI-edited derivative, created with the built-in image generation tool. Its [base prompt](shambu-binoculars-base.prompt.txt) and [refinement prompt](shambu-binoculars.prompt.txt) are preserved.
